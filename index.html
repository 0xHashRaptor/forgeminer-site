What it isЧто это

Not a wrapper. A native miner. Не обёртка. Нативный майнер.

ForgeMiner is closed-source and built from the metal up. Every algorithm ships a separate per-architecture build for each supported card, auto-selected at launch — so a Pascal rig and a Blackwell rig each run code written for them, not a lowest-common-denominator kernel. Near-zero CPU load keeps the GPUs fed even on weak hosts, crowded rigs and slow x1 risers. ForgeMiner — closed-source, собран с самого низкого уровня. Под каждый алгоритм для каждой карты идёт отдельная сборка под её архитектуру, выбирается автоматически при запуске — так что и Pascal-риг, и Blackwell-риг гоняют код, написанный именно под них, а не универсальное «ядро на всех». Почти нулевая нагрузка на CPU держит карты загруженными даже на слабом хосте, забитом риге и медленных x1-райзерах.

Quick startБыстрый старт

Running in under a minute. Запуск меньше чем за минуту.

Download, set your wallet, start. On Windows pick the ready-made .bat for your coin, pool and region; on Linux one command; on HiveOS a custom-miner slot. Скачать, вписать кошелёк, запустить. На Windows — готовый .bat под монету, пул и регион; на Linux — одна команда; на HiveOS — слот кастомного майнера.

Flags & tuningФлаги и тюнинг

Every knob, one reference. Все настройки в одном месте.

Anything you pass on the command line has an FORGE_* environment-variable twin — handy for HiveOS extra-config and .bat files. Overclock and fans can be one value for all cards, or a comma list mapped to --gpu. У любого флага командной строки есть двойник-переменная FORGE_* — удобно для extra-config в HiveOS и .bat. Разгон и кулеры — одно значение на все карты или список через запятую под --gpu.

OverclockРазгон

ForgeMiner is core-clock bound and memory-light — push the core high, leave memory low. Overclocking needs root (Linux/HiveOS) or Administrator (Windows). ForgeMiner упирается в частоту ядра и нетребователен к памяти — поднимайте ядро, память можно оставить низкой. Разгон требует root (Linux/HiveOS) или Администратора (Windows).

Fan controlУправление кулерами

A fixed speed, or a temperature curve. With no fan flag the driver keeps automatic control; it's restored on exit. Setting fans needs Administrator/root. GeForce cards have a ~30% hardware fan floor. Фиксированная скорость или температурная кривая. Без флага — автоматика драйвера; она восстанавливается при выходе. Управление требует Администратора/root. У GeForce есть аппаратный порог ~30%.

# fixed speed --fan 70 every GPU at 70% --fan 60,70,80,100 per-GPU (maps to --gpu order) # temperature curve — temp°C:fan% (linear between points) --fan-curve 45:30,60:55,70:75,80:100 # ≤45°C→30% · 60°C→55% · 70°C→75% · ≥80°C→100% · 65°C→~65%
Monitoring APIAPI мониторинга

Off by default, read-only, one port. It only ever reports stats — it can't control or reconfigure the miner. Keep 127.0.0.1 for local-only; use 0.0.0.0 only behind your own router/firewall/VPN. Выключен по умолчанию, только чтение, один порт. Только отдаёт статистику — управлять майнером через него нельзя. Оставляйте 127.0.0.1 для локального доступа; 0.0.0.0 — только за своим роутером/файрволом/VPN.
