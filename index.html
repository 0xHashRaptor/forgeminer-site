What it isЧто это

Not a wrapper. A native miner. Не обёртка. Нативный майнер.

ForgeMiner is closed-source and built from the metal up. Every algorithm ships a separate per-architecture build for each supported card, auto-selected at launch — so a Pascal rig, a Blackwell rig and a Radeon RDNA 3 rig each run code written for them, not a lowest-common-denominator kernel. Near-zero CPU load keeps the GPUs fed even on weak hosts, crowded rigs and slow x1 risers. ForgeMiner — closed-source, собран с самого низкого уровня. Под каждый алгоритм для каждой карты идёт отдельная сборка под её архитектуру, выбирается автоматически при запуске — так что и Pascal-риг, и Blackwell-риг, и риг на Radeon RDNA 3 гоняют код, написанный именно под них, а не универсальное «ядро на всех». Почти нулевая нагрузка на CPU держит карты загруженными даже на слабом хосте, забитом риге и медленных x1-райзерах.

Thermal guardТермозащита

--temp-limit pauses only the card that overheats — core or VRAM, whichever is hotter — and --temp-resume brings it back once it cools. The rest of the rig keeps mining.--temp-limit ставит на паузу только перегретую карту — по ядру или VRAM, что горячее, — а --temp-resume возвращает её после остывания. Остальные карты рига майнят дальше.

Support is per-architecture — every card in a listed generation runs its matching kernel, desktop and laptop/mobile alike. RTX 20-series and CMP cards need NVIDIA driver 545 or newer; the RTX 50-series needs 580 or newer. Pearl, QubitCoin, KawPow, Cryptix and Xelis run on every listed generation, from Pascal (GTX 10-series / P102-100 / P104-100 / P106 / P108) and Volta (Tesla V100) up to Blackwell. BTX needs Volta (Tesla V100) or Turing (RTX 20 / CMP 40HX–70HX) and newer — it does not run on Pascal or the CMP 170HX. Conflux runs from Pascal up on cards with more than 8 GB (GTX 1080 Ti, Tesla V100, RTX 20 and newer), not on the CMP 170HX. Quantus, NOID and QubitCoin run from Pascal (GTX 10-series) up, Tesla V100 included, but not on the CMP 170HX; a card without a kernel for the chosen coin says so in one line while the rest of the rig mines. On Hopper, Pearl, Cryptix and QubitCoin have their own builds; Xelis, BTX, Conflux, NOID and Quantus do not. Поддержка — на уровне архитектуры: любая карта из указанного поколения запускает своё ядро, десктопная и ноутбучная одинаково. Для RTX 20 и CMP нужен драйвер NVIDIA 545+, для RTX 50 — 580+. Pearl, QubitCoin, KawPow, Cryptix и Xelis работают на каждом поколении — от Pascal (GTX 10-й серии / P102-100 / P104-100 / P106 / P108) и Volta (Tesla V100) до Blackwell. BTX нужен Volta (Tesla V100) или Turing (RTX 20 / CMP 40HX–70HX) и новее — на Pascal и CMP 170HX он не идёт. Conflux работает начиная с Pascal на картах с памятью больше 8 ГБ (GTX 1080 Ti, Tesla V100, RTX 20 и новее), кроме CMP 170HX. Quantus, NOID и QubitCoin работают начиная с Pascal (GTX 10-й серии), включая Tesla V100, но не на CMP 170HX; карта, для которой у выбранной монеты нет ядра, скажет об этом одной строкой, остальные карты рига майнят. На Hopper свои сборки есть у Pearl, Cryptix и QubitCoin; у Xelis, BTX, Conflux, NOID и Quantus — нет.

AMD Radeon RX 400 / 500 (Polaris) and RX 5000 – RX 9000 (RDNA 1–4), on Linux / HiveOS and Windows. Every coin except BTX, with the same command lines as on NVIDIA. Conflux needs a card with more than 8 GB there too; Pearl on the RX 9060 XT runs at the stock core voltage only. The RX 6500 XT / 6400 and integrated Radeon graphics are not supported. On plain Linux install AMD's OpenCL runtime (ROCm) and run the miner as root or as a user in the render group; HiveOS has everything. The RX 9000 series needs a recent driver — on HiveOS a current image. A rig with NVIDIA and AMD cards mines in one ForgeMiner: NVIDIA cards are numbered first, then AMD in PCI bus order; FORGE_AMD=1 mines on the AMD cards only, FORGE_AMD=0 on the NVIDIA cards only. AMD Radeon RX 400 / 500 (Polaris) и RX 5000 – RX 9000 (RDNA 1–4), на Linux / HiveOS и Windows. Все монеты, кроме BTX, с теми же командными строками, что на NVIDIA. Conflux и здесь требует карту больше 8 ГБ; Pearl на RX 9060 XT работает только на штатном напряжении ядра. RX 6500 XT / 6400 и встроенная графика Radeon не поддерживаются. На обычном Linux поставьте OpenCL от AMD (ROCm) и запускайте майнер от root или пользователем из группы render; в HiveOS всё уже есть. Для RX 9000 нужен свежий драйвер — на HiveOS свежий образ. Риг с картами NVIDIA и AMD майнит в одном ForgeMiner: сначала нумеруются NVIDIA, потом AMD по порядку шины PCI; FORGE_AMD=1 — майнить только на AMD, FORGE_AMD=0 — только на NVIDIA.

CMP 40HX, 50HX, 70HX and 90HX — hardware unlock built into the miner (Linux), any kernel. Run sudo forge --cmp-install once and the card runs at full speed instead of being throttled. CMP 30HX is a permanent hardware limitation, never supported. Full walkthrough — wiki · CMP hardware unlock. CMP 40HX, 50HX, 70HX и 90HX — аппаратный разлок встроен в майнер (Linux), любое ядро. Один раз запустите sudo forge --cmp-install — и карта работает на полной скорости вместо задушенной. CMP 30HX — постоянное аппаратное ограничение, никогда не будет поддержана.     Flags & tuningФлаги и тюнинг
    
      
    
        Every knob, one reference.
        Все настройки в одном месте.
      
    
      
    
        Most command-line flags have a FORGE_* environment-variable twin — handy for HiveOS extra-config and .bat files. Overclock and fans can be one value for all cards, or a comma list mapped to --gpu.
        У большинства флагов командной строки есть двойник-переменная FORGE_* — удобно для extra-config в HiveOS и .bat. Разгон и кулеры — одно значение на все карты или список через запятую под --gpu.

    OverclockРазгон
    
      
    
        ForgeMiner is core-clock bound and memory-light — push the core high, leave memory low. KawPow and Conflux are the exception: they read a large dataset from memory, so keep the memory clock up for them. Overclocking needs root (Linux/HiveOS) or Administrator (Windows). AMD Radeon takes the same flags plus the core voltage. On exit every card goes back to its previous power limit, offsets and clocks (--oc-keep leaves the overclock on).
        ForgeMiner упирается в частоту ядра и нетребователен к памяти — поднимайте ядро, память можно оставить низкой. Исключение — KawPow и Conflux: они читают из памяти большой набор данных, им частоту памяти оставляйте высокой. Разгон требует root (Linux/HiveOS) или Администратора (Windows). AMD Radeon принимает те же флаги плюс напряжение ядра. При выходе каждая карта возвращается к прежним лимиту мощности, оффсетам и частотам (--oc-keep оставляет разгон).

На других картах не действует.

На GTX 10 / RTX 20 810 держит память на 810 МГц — Quantus и NOID сохраняют хешрейт при меньшей мощности.

    --vddc—Absolute core voltage, mV (alias --vcore): AMD RX 5000 / 6000 (RX 7000 / 9000 take only the offset), and NVIDIA on Linux. --voltage-recover puts a card back after an interrupted run.Абсолютное напряжение ядра, мВ (псевдоним --vcore): AMD RX 5000 / 6000 (RX 7000 / 9000 принимают только смещение) и NVIDIA на Linux. --voltage-recover вернёт карту после прерванного запуска.

С --gpu — только эти карты.

    Fan controlУправление кулерами
    
      
    
        A fixed speed, or a temperature curve. With no fan flag the driver keeps automatic control; it's restored on exit. Setting fans needs Administrator/root. GeForce cards have a ~30% hardware fan floor. On AMD --fan sets a static speed; --fan-curve is NVIDIA-only for now.
        Фиксированная скорость или температурная кривая. Без флага — автоматика драйвера; она восстанавливается при выходе. Управление требует Администратора/root. У GeForce есть аппаратный порог ~30%. На AMD --fan задаёт постоянные обороты; --fan-curve пока только для NVIDIA.
      
    
      
    # fixed speed
--fan 70                 every GPU at 70%
--fan 60,70,80,100       per-GPU (maps to --gpu order)
--fan 70,70,*,70         * = that card stays on automatic control

# temperature curve — temp°C:fan%  (linear between points)
--fan-curve 45:30,60:55,70:75,80:100
#  ≤45°C→30% · 60°C→55% · 70°C→75% · ≥80°C→100% · 65°C→~65%

# env: FORGE_FAN=70 · FORGE_FANCURVE=45:30,60:55,70:75,80:100
    

      
    ReliabilityНадёжность
    
      
    
        --temp-limit / --temp-resume pause a card automatically once it hits a temperature threshold, and resume it once it cools back down. --oc-delay delays applying your overclock by N seconds after startup, for rigs where clocking straight from boot causes instability.
        --temp-limit / --temp-resume сами ставят карту на паузу при перегреве и возобновляют майнинг после остывания. --oc-delay откладывает применение разгона на N секунд после старта — для ригов, где мгновенный разгон сразу после загрузки вызывает нестабильность.
      
    
      
    # pause at 80°C, resume at 70°C; apply overclock 20s after startup
--temp-limit 80 --temp-resume 70 --oc-delay 20
# env: FORGE_TEMP_LIMIT=80 FORGE_TEMP_RESUME=70 FORGE_OC_DELAY=20
    

      
    CMP hardware unlock (Linux)Аппаратный разлок CMP (Linux)
    
      
    
        CMP 40HX, 50HX, 70HX and 90HX ship with a hardware throttle — stock hashrate is a small fraction of what the chip can actually do. Forge can install a hardware-unlock helper directly on the rig: one command, one reboot, the card then runs at full speed. The helper is embedded in the miner binary; no external download, no manual steps. Everything is reversible via --cmp-rollback. Only the detected CMP cards are touched; every other card on a mixed rig runs untouched. CMP 30HX is detected but never attempted — a permanent hardware limitation, not a bug.
        CMP 40HX, 50HX, 70HX и 90HX с завода задушены аппаратно — стоковый хешрейт составляет лишь малую долю того, на что способен чип. Форж умеет поставить хелпер разлока прямо на риге: одна команда, одна перезагрузка, карта работает на полной скорости. Хелпер встроен в бинарь; ничего внешнего скачивать не нужно. Всё обратимо через --cmp-rollback. Затрагивает только обнаруженные CMP-карты; остальные работают без изменений. CMP 30HX обнаруживается, но никогда не трогается — постоянное аппаратное ограничение, не баг.
      
    
      
    
        Builds from source for whatever kernel the rig is actually running — no exact kernel pin, tested clean across 10 different kernel versions. NVIDIA driver 610.43.03 still required. Full walkthrough — wiki · CMP hardware unlock (Русский).
        Собирается из исходников под то ядро, что реально стоит на риге — точная привязка ядра больше не нужна, протестировано без единого сбоя на 10 разных версиях ядра. Драйвер NVIDIA 610.43.03 по-прежнему обязателен. Полная инструкция — wiki · CMP аппаратный разлок (English).

    --cmp-installInstall the hardware unlock helper, reboot the rig after a 10-second cancel window. Можно оставить в полётнике HiveOS навсегда — если разлок уже стоит, форж напечатает одну строку и сразу идёт майнить, без цикла переустановок.

    --cmp-verifyPrint live per-card unlock status. On CMP 40HX/50HX the register is walled off by the driver — live status is the miner's hashrate.Показать живой статус разлока по картам. На CMP 40HX/50HX регистр закрыт драйвером — живой источник правды — хешрейт майнера.
    
          
    --cmp-rollbackRestore the previous NVIDIA driver from backup and reboot (10-second cancel window). Add --no-reboot to reboot yourself.Восстановить предыдущий NVIDIA-драйвер из бэкапа и ребут (10 секунд на отмену). Добавьте --no-reboot, чтобы ребутнуться самому.

Interactive terminals (Windows Terminal, PowerShell 7, HiveOS ssh, tmux) still get the full dashboard.
        Когда stdout не живой терминал (PSEXEC, | cat, cron, лог-файл, web-консоль), форж сам вычищает ANSI-цвета и меняет Unicode box-drawing на ASCII — больше нет каши типа räć в Windows cmd или в логах rental-платформ. Интерактивные терминалы (Windows Terminal, PowerShell 7, HiveOS ssh, tmux) как раньше получают полный дашборд.

    Monitoring APIAPI мониторинга
    
      
    
        Off by default, read-only, one port. It only ever reports stats — it can't control or reconfigure the miner. Keep 127.0.0.1 for local-only; use 0.0.0.0 only behind your own router/firewall/VPN.
