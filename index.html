Under the hoodПод капотом

Not a wrapper. A native miner. Не обёртка. Нативный майнер.

ForgeMiner is closed-source and built from the metal up. Every algorithm ships a separate build for each architecture, picked automatically at launch — so a Pascal rig, a Blackwell rig and a Radeon RDNA 3 rig each run code written for them, not a lowest-common-denominator kernel. Near-zero CPU load keeps the cards fed even on weak hosts, crowded rigs and slow x1 risers. ForgeMiner — майнер с закрытым исходным кодом, собранный с самого низкого уровня. Под каждый алгоритм идёт отдельная сборка под каждую архитектуру, она выбирается сама при запуске — так что и Pascal-риг, и Blackwell-риг, и риг на Radeon RDNA 3 гоняют код, написанный именно под них, а не универсальное «ядро на всех». Почти нулевая нагрузка на CPU держит карты загруженными даже на слабом хосте, забитом риге и медленных x1-райзерах.

    OverclockРазгон
    
        
    
          ForgeMiner is core-clock bound and memory-light — push the core high, leave memory low. KawPow and Conflux are the exception: they read a large dataset from memory, so keep the memory clock up for them. Overclocking needs root (Linux/HiveOS) or Administrator (Windows). AMD Radeon takes the same flags plus the core voltage. On exit every card goes back to its previous power limit, offsets and clocks (--oc-keep leaves the overclock on).
          ForgeMiner упирается в частоту ядра и нетребователен к памяти — поднимайте ядро, память можно оставить низкой. Исключение — KawPow и Conflux: они читают из памяти большой набор данных, им частоту памяти оставляйте высокой. Разгон требует root (Linux/HiveOS) или администратора (Windows). AMD Radeon принимает те же флаги плюс напряжение ядра. При выходе каждая карта возвращается к прежним лимиту мощности, офсетам и частотам (--oc-keep оставляет разгон).

    CMP hardware unlock (Linux)Аппаратный разлок CMP (Linux)
    
        
    
          CMP 40HX, 50HX, 70HX and 90HX ship with a hardware throttle — stock hashrate is a small fraction of what the chip can actually do. Forge installs an unlock helper straight on the rig: one command — sudo forge --cmp-install — one reboot, and the card runs at full speed. The helper is embedded in the miner binary — no external download, no manual steps. Only the detected CMP cards are touched; everything is reversible with --cmp-rollback. CMP 30HX is detected but never attempted — a permanent hardware limitation, not a bug.
          CMP 40HX, 50HX, 70HX и 90HX с завода задушены аппаратно — стоковый хешрейт составляет лишь малую долю того, на что способен чип. Форж ставит хелпер разлока прямо на риге: одна команда — sudo forge --cmp-install — одна перезагрузка, и карта работает на полной скорости. Хелпер встроен в бинарь — ничего внешнего скачивать не нужно. Затрагиваются только обнаруженные CMP-карты; всё обратимо через --cmp-rollback. CMP 30HX обнаруживается, но никогда не трогается — постоянное аппаратное ограничение, не баг.
        
    
        
    
          Builds from source for whatever kernel the rig is actually running — no exact kernel pin, tested clean across 10 different kernel versions. NVIDIA driver 610.43.03 still required. Full walkthrough — wiki · CMP hardware unlock (Русский).
          Собирается из исходников под то ядро, что реально стоит на риге — точная привязка ядра не нужна, протестировано без единого сбоя на 10 разных версиях ядра. Драйвер NVIDIA 610.43.03 по-прежнему обязателен. Полная инструкция — wiki · CMP аппаратный разлок (English).
        
    
        
    
        
    
          
    FlagФлагWhat it doesЧто делает
    
          
            
    --cmp-installInstall the hardware unlock helper, reboot the rig after a 10-second cancel window. Можно оставить в полётнике HiveOS навсегда — если разлок уже стоит, форж напечатает одну строку и сразу идёт майнить, без цикла переустановок.
    
            
    --cmp-install --no-rebootInstall only — you reboot the rig yourself.Только установить — ребут делаете сами.
    
            
    --cmp-verifyPrint live per-card unlock status. On CMP 40HX/50HX the register is walled off by the driver — live status is the miner's hashrate.Показать живой статус разлока по картам. На CMP 40HX/50HX регистр закрыт драйвером — живой источник правды — хешрейт майнера.
    
            
    --cmp-rollbackRestore the previous NVIDIA driver from backup and reboot (10-second cancel window). Add --no-reboot to reboot yourself.Восстановить предыдущий NVIDIA-драйвер из бэкапа и ребут (10 секунд на отмену). Добавьте --no-reboot, чтобы ребутнуться самому.
